# 2026-09-07 二次确认改为弹窗

原先点击批准等按钮后，经营台在页首插入 OperationTask 卡片并尝试滚动定位，用户在长列表下方容易错过确认步骤。现在使用遮罩弹窗，在当前视口显示操作对象、说明、必要字段和确认按钮。

## 覆盖范围

- 公共 OperationTask：会员、财务、采购库存、前台、场地、教练、主理人、赛事、商户九个经营页面的审批、变更与业务确认。
- 公共 ReasonForm：订单退款、培训退费、赛事退出、场地履约及账号注销申请/撤回。
- 电脑扫码登录的识别码与授权确认。
- 已有原生确认弹窗继续使用；普通录入和查询表单不增加额外确认步骤。

## 行为

- 弹窗顶部显示标题与关闭按钮，底部保留取消和明确的提交按钮。遮罩拦截背景操作，长内容在弹窗内滚动。
- 移除页首滚动定位；校验失败定位弹窗内首个错误字段，失败保留输入。
- 提交中禁用重复提交和关闭，处理成功继续在弹窗中反馈；取消不发送业务请求。
- 适配安全区与键盘高度；H5 锁定背景滚动，支持 Tab 焦点循环、Enter/空格操作、Escape 关闭。
- 沿用原有权限、身份变化检查、业务接口和审计，不改变批准、退款等业务规则。
