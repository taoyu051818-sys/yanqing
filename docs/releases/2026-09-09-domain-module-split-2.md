# 赛事执行流程与培训消课冲正拆分

赛事主服务原本同时承担报名、配对、比分、排名、积分和履约；培训主服务同时承担正常消课和冲正复核。本轮继续按完整业务流程拆分，保留原有服务方法作为转发入口，不变更控制器接口或响应合约。

## 职责归属

| 文件 | 负责内容 |
| --- | --- |
| `events/event-rounds.ts` | 开启下一轮、人工调整配对、并发与幂等核验、审计 |
| `events/event-scoring.ts` | 比分提交与纠正、让分校验、重复提交与封账保护 |
| `events/event-completion.ts` | 完赛排名、积分发放、未到场处理、订单履约补记 |
| `events/event-competition-policy.ts` | 固定赛制、人数、队员、轮次与配对完整性校验、赛事管理权限 |
| `events/event-standings.ts` | 配对或比分纠正后的积分、胜负、分差与对手历史重算 |
| `training/training-consume-corrections.ts` | 消课冲正查询、申请、批准、驳回，反向收入流水、余额与积分恢复、订单履约重开 |
| `training/training-access.ts` | 消课确认与冲正共用的审批权限和角色判断 |
| `training/training-settlement-ledger.ts` | 增加从主服务移入的锁账期检查，正常消课和冲正共用 |

独立命令显式接收数据库依赖，不回调整个大服务对象。原事务隔离级别、原状态条件、幂等核验、申请人与复核人分离、库存/资金及积分处理和审计保持原逻辑。固定赛制常量由领域策略持有，DTO 单向引用；原 DTO 的常量导出保留兼容。

扩展现有架构回归检查，将新领域入口纳入静态依赖链检查，防止重新依赖赛事、球局和培训主服务。
