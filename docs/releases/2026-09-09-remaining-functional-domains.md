# 2026-09-09 其余大文件按功能领域拆分

## 结果

- 11 个后端聚合服务拆为 43 个领域服务；报表、待办、经营分析、微信通知、对账及培训冲正另行分离查询、规则与命令。
- 后端生产 TypeScript 文件（不含生成代码和测试）最大 684 行；小程序最大页面入口 757 行。
- 小程序拆出 37 个业务区块、25 个操作/加载/计算 composable、5 个培训表单状态模块。
- 模拟接口原约 13,600 行的 router.ts 缩至 479 行；171 个有序业务分支分布在 57 个模块中，模拟数据状态和政策按领域归档。
- 无数据库迁移，原业务流程、角色权限和管理员/前台代订绕过规则保持不变。

目录规范见 [按功能领域组织代码](../architecture/functional-domains.md)。

## 验收

- API lint、Nest 构建通过。
- API 单元测试 861 项通过；普通运行跳过的 286 项数据库用例另在隔离 PostgreSQL 中全部通过：shared 238、training 13、reporting 13、boss_events 8、amounts 14。
- API e2e 12 项通过，包含新增 150 条路由装配和权限合约；原赛事/培训 56 条路由合约继续通过。
- 小程序测试 324 项通过；无 Intl 环境的 13 个页面 setup 在后续加载/表单拆分后复验通过。
- 小程序类型检查、H5 构建、微信小程序构建及分包检查通过。
- 259 个后端命令/规则方法、134 个原页面操作函数经过拆分前后归一化 JavaScript 语法树比对；只调整依赖传递和提取后的调用名；171 个模拟路由分支的匹配次序另行核对一致。
- 本地 H5 mock 浏览器抽验财务弹窗、库存分区/采购表单、治理标签切换、培训、赛事、经营总览和会员活动页；检查 375 像素竖屏及 812 像素横屏，页面无控制台错误。

数据库测试首次运行发现测试仍调用被提取的私有方法，已改为执行新领域函数。重复使用测试库造成历史结算夹具冲突，最终用全新隔离库运行全部分组通过。没有将失败用例跳过。

## 发布范围与限制

本次为代码重构，提交 GitHub；未部署线上。微信外部调用在自动化中使用测试替身，H5 验收使用本地模拟数据；本次不声称完成微信真机或真实收付款验收。

页面入口仍保留跨区块状态与较多组件绑定。历史 PC 原型和数据库种子数据未按业务服务方式继续拆分。
