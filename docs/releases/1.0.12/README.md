## 本版内容

- 订场切换日期或订场模式时清空旧数据，加载失败显示重试，避免沿用上一天的预约情况。
- 培训课表按日期和课程名称先筛选再分页，支持加载更多及历史课次详情查询。
- 统一版本与验收文档入口，将核心界面流程加入持续集成检查。

PPT 同时展示试听回填、连续代订与退款异常恢复等已有能力的回归验证，不将其写成本版首次增加的功能。界面图片使用 H5 模拟数据，不是真机或实际经营记录。
