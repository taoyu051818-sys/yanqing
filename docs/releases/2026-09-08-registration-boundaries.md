# 第二轮抽查缺陷修复：报名、候补和会员有效期

修复第二轮审查确认的四个问题，保留已有接口和财务审批流程。

## 行为变化

- 球局候补记录增加入队版本和时间。每轮晋级使用独立幂等键，同一轮重试保持幂等；历史订单仍保留，重新入队按本轮时间排队。解决再次晋级触发唯一键冲突、连带其他会员取消订单回滚的问题。用户建单不能占用 `SYSTEM:` 命名空间。
- 赛事先明确检查代报名权限。没有权限且不是会员的教练、主理人、财务、商户账号直接拒绝；混合会员角色按会员授权规则处理。前台、赛事管理员和管理员的原有代报名权限保留。
- 球局报名和候补在开场时截止，付款保留期取“下单后 15 分钟”和开场时间中的较早者。付款选项、付款提交、预支付重试、支付终结器和后台清理共同校验。截止后到达的微信成功回调登记实际收款并生成待审核补偿退款，不确认已失效席位；重复通知不重复收录或创建退款。
- 赛事优惠同时检查会员等级与有效期。过期、未记录有效期的金卡/黑金档案不再自动获得优惠；有效会员价格保持原逻辑。下单记录资格证据，候补记录在入队审计中保留依据，已约定订单价格不会在付款时被静默修改。

抽出 `game-registration-policy.ts` 和 `membership-eligibility.ts`，让规则集中表达。修复原有测试夹具缺少活动时间和新字段的问题，没有给生产代码增加“兼容不完整测试替身”的绕过逻辑。
