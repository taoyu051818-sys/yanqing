# 小程序 v0.2.5：弹窗风格统一

审批等二次确认弹窗沿用系统的球场绿、金色点缀、浅底卡片和圆角按钮，统一标题、遮罩、关闭图标、输入框、选项与底部操作栏。去掉按钮默认伪元素边框和未出现错误时的占位空白。

影响共用 ActionDialog、经营台 OperationTask 和退款等流程使用的 ReasonForm。提交、校验与权限规则保持现有逻辑；H5 补充观察 uni-button 的动态禁用状态，使键盘操作及无障碍标记随输入同步。
