# 第十六轮修复：会话隔离与推荐绑定重试

## 修复行为

- 每次登录保存或退出都会更新会话版本，即使新旧令牌相同，也能识别旧请求。普通请求、头像上传和报表下载的过期响应不会覆盖当前状态或触发新会话退出。
- 会话存储在异步步骤之间校验版本；退出后不恢复旧资料，旧头像上传完成后不再继续提交昵称，旧登录不能覆盖后发登录或提前关闭其加载状态。当前会话收到 401 仍清理身份和用户资料。
- 推荐绑定仅对已确认终止的 400/404 错误清理邀请信息。网络故障、401、409、429 和服务端错误保留邀请，下一次登录或资料恢复时重试。绑定成功但资料刷新失败时，下一次通过已有推荐关系完成收尾。
- 清理邀请时核对本次使用的邀请码，避免旧请求删除期间新打开分享卡片所带来的邀请。
- 模拟请求通过同一会话检查；小程序模拟登录的令牌由会话存储接受结果后统一保存，保留独立 mock 测试调用的默认行为。
