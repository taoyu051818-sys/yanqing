# 经营工作台白屏修复

2026-09-06：用户反馈经营台多个入口白屏。代码检查和受限 JavaScript 环境回放发现：课程、赛事、财务、球局、联盟、场地六个页面在 setup 初始化日期默认值时，直接使用 `Intl.DateTimeFormat().formatToParts()`。当运行环境不提供 Intl 时，初始化抛出 `Cannot read properties of undefined (reading 'DateTimeFormat')`，页面无法正常创建。尚未获得用户设备上的原始错误日志，因此此处记录的是已复现的代码根因，不将开发者工具的无响应推断为用户手机白屏原因。

## 修复

- 将上述六个页面的日期默认值统一改为共用的北京时间工具，通过时间戳加 UTC+8 后读取 UTC 日期，不依赖 Intl、系统语言或设备时区。
- 同时替换经营工作台今日课程统计、场地封场时间显示和联盟结算日期显示中的同类调用。
- 保留北京时间跨日、昨日关账、未来预约日期、闰年及跨年计算；修改日期展示与初始化，不调整业务金额、订单或权限。
- 增加运行环境回归测试，直接执行 12 个经营分包页面和工作台页面的 TypeScript setup 及本地依赖，在缺少 Intl 的隔离 VM 中核实初始化。原代码 6 个页面失败，修复后 13 个页面全部通过。该测试不代替真机页面渲染与微信平台验收。
