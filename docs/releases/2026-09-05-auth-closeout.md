## 管理员初始化工具

工具不开放 HTTP 路由，不内置目标用户或手机号。默认仅预览；必须用用户已指定的完整手机号或核实后的精确编号二选一。公开微信昵称不作为 CLI 的写入选择条件。

```bash
node --env-file=/path/to/api.env apps/api/scripts/bootstrap-admin.mjs --user-id '<已核实用户编号>'
node --env-file=/path/to/api.env apps/api/scripts/bootstrap-admin.mjs \
  --user-id '<已核实用户编号>' --expected-user-id '<预览返回的同一编号>' \
  --operator '<真实操作来源>' --reason '<项目所有者的明确指令依据>' --apply
```

若账号绑定手机号，也可用 `--phone '<完整手机号>'` 替代 `--user-id`；手机号输出自动掩码。预览是只读事务；执行时锁定用户/角色表、重新核对账号与现有管理员，授权与审计原子提交。存在另一位有效微信超级管理员时，应改用正常岗位管理。
