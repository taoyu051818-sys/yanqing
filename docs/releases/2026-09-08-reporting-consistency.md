# 第六轮抽查修复：报表与配置一致性

修复周结算金额重复计入日结、参数并发版本重叠、导出表间状态矛盾、扫描覆盖人工处理说明，以及停用场地后使用率失真的五类问题。服务端变更，客户端接口保持兼容。

## 业务行为

- 培训结算首次入账时，在状态转换事务中记录 settledAt；幂等重试保持原时间。日结按培训和联盟的入账日归属金额一次，界面已有金额字段保持兼容，新快照声明 SETTLED_AT_V2。历史锁定快照不改写。
- 参数读取、权限/时间校验、关闭旧版本和创建新版本都在同一事务内按 key 加锁。数据库排斥约束禁止生效区间重叠；不同时间并发保存如违反版本顺序会返回 409，正确重试保持幂等。列表与 resolve 都保留最新有效版本。
- 管理员和财务导出的所有工作表使用一次 RepeatableRead 只读快照。Excel 编码和导出审计在读事务结束后执行，保留角色白名单、脱敏和单表行数限制。
- 风险人工处理记录存入 handling，自动扫描只更新观测 evidence。接口组合原有证据形状，不改变已处理终态；并发扫描不会抹去处理人及原因。
- 老板摘要与驾驶舱共用 venue-capacity 区间计算，按同一组启用场地计算容量、预约和封场；合并重叠区间，排除创建前容量，支持部分日和跨日查询。

## 数据库迁移

新增第 41 个迁移 20260908200000_reporting_consistency：参数有效期约束、培训 settledAt、两类结算状态/入账时间一致性约束、入账索引、风险处理独立字段及审计恢复。

历史参数重叠或已结算单缺少可信入账证据会阻止迁移，并在事务内完整回滚，不自动选择一个旧参数或猜测财务日期。培训入账时间从成功结算审计恢复；风险说明优先从真实状态转换审计恢复。旧日结快照原样保留。
