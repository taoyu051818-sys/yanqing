# 1.0.12 真机验收步骤

状态：候选版本准备中，尚未完成发布或真机验收。先核对 [项目状态](project-status.md) 中的发布状态；不要在旧版 1.0.11 上判断本轮修复。既有全岗位任务沿用 [岗位验收表](acceptance-2026-09-26-role-workflows.md)，版本核对以本文件为准。

1. 发布后，在微信后台将本次上传的 1.0.12 选择为体验版。手机退出再进入，在“我的 → 关于金羽会员”核对版本、体验版标识和构建提交，复制版本信息。
2. 游客打开订场并切换日期，确认看到对应日期的预约情况且不弹登录。断网后切换另一日期，应显示加载失败和重试，不能继续显示上一天的场地状态；恢复网络点重试。
3. 前台连续代订两笔，确认成功回执中的会员、时间、场地；“同一会员再订”保留会员，“为下一位订场”清除会员，新单不携带旧场次。
4. 管理员打开培训，依次查看今日、明日、全部，搜索课程。数量较多时点“加载更多课次”，从历史课次或待办进入详情，确认能看到正确课次及名单。
5. 前台预约试听，搜索或新增学员。缺课次时点去排课，完成后返回，学员和备注应保留，新课次自动选中。管理员新建课程，确认适用人群有“不限”、姓名/金额可输入和保存。
6. 教练用本人账号查看任教班级；不能查看其他教练的私有课次。管理员用同一入口核对具备权限的课次。
7. 会员查看代订单并本人支付；管理员对现场同意的验收单发起退款，核对真实到账与双方订单状态。不要将“处理中”记为到账。
