# 球馆设置与代订权限修复

## 入口和行为

- 小程序合并用户主角色与附加角色；主角色为前台、管理员、超级管理员时显示代订入口。
- 管理员、超级管理员：经营台 → 球馆设置。可以编辑名称、地址、联系电话、导航经纬度，每日营业时间，新增、重命名、排序、停用场地；价格按钮进入现有价格版本管理。
- 首页与订场页通过公开接口显示球馆资料，游客无须登录。
- 每日营业时间目前采用统一整点小时表，支持结束于24:00，不支持跨午夜或按星期设置不同营业时间。
- 新增小时未定价时不可按0元下单；管理员需维护并启用价格规则。历史订单和已有时段价格保留。
- 管理员及前台原有特殊代订能力保持；普通会员受开放场地和营业时段约束。
- 设置保存有事务、版本冲突检查与审计；实际经营数据需管理员填写，本次未修改线上数据。

## 真机验收步骤

1. 管理员登录，进入订场页，确认代会员订场入口及会员选择；前台账号重复确认，普通会员无代订入口。
2. 进入经营台 → 球馆设置，填写真实名称、地址、电话、位置和营业时间，确认弹窗后保存。
3. 修改场地名称，停用多余场地；需要时新增场地。检查开放数量和排序。
4. 进入场地价格，按时段、星期和生效日期创建/启用真实价格。
5. 退出登录，浏览首页和订场页，确认信息、可订时段、场地数量及价格，且浏览不主动弹出登录。
6. 登录会员检查原订单仍存在；在测试环境验证未定价时段不可提交订单。
