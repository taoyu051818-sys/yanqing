# 培训入口与课包限制修复（2026-09-23）

## 实际原因

线上 API 仍为 `6aaa68b`，最近的小程序上传记录为 1.0.9；二者均早于 `87bf05c` 中的培训输入和“不限”修复。此前的本地验证不能视为用户已经收到更新。

9 月 23 日只读核验发现唯一规则确实为 PUBLISHED，但生效时间是北京时间 9 月 24 日 09:00。旧表单默认明天 09:00，导致“已经配置却仍无法启用”的误解。保留用户配置及其生效计划，不在数据库中直接改业务记录。

## 改动

- 规则入口改名“限制”，说明三个上限的业务用途；使用中、已发布待生效、已结束分别展示。
- 默认立即生效；指定时间需要用户主动选择。沿用既有配置，常用表单只有课次、天数、金额三个数值，备注选填，更多设置与记录折叠。
- 保存/取消固定在底部；失败保留输入并就近显示错误。课程页面可直接进入限制设置，不必猜测错误含义。
- 服务端以实际发布时间确定立即生效时间；幂等命令使用稳定的 IMMEDIATE 意图，重试不会因当前时间变化而冲突。
- 立即发布保留后续预约版本，以其生效时间作为本次版本结束边界；旧版本仅关闭对应区间，历史合同快照不改。
- 发布包同时包含此前的“不限”课程、试听新增学员、可选创建备注、操作弹窗输入修复。

## 验证

- 规则服务单测 12 项通过。
- 本机隔离 PostgreSQL 培训分组 3 文件 19 项通过，包括立即生效、预约接替、幂等及 ALL 成人/青少年报名。
- 新规则表单/状态/模拟业务回归 9 项通过。
- 全量本地业务测试通过；最终构建、CI、部署、上传结果另记发布记录。
- 375px 浏览器实际操作：显示待生效、沿用三个原值、立即保存后显示使用中。
