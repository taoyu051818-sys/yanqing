# 岗位操作减负实施与验收

日期：2026-09-22。基线：`87bf05c`。本轮完成本地代码、构建和验收，未部署服务器或上传微信体验版。

## 已落地

- **教练与培训管理员**：逐人选择到场后统一保存；消课建议、扣课入账分别提供本课批量入口。默认不勾选学员；批量确认明确说明每人扣减 1 课次。逐项显示失败原因，成功项移出重试范围，网络中断保留每人的幂等键。异常补录、请假和冲正沿用独立流程。
- **前台代订**：工作台“代会员订场”直接进入代订模式，页面内搜索会员，输入后自动查询；少量首屏结果可继续加载。创建后点“继续订场”会清空上次会员，避免连续代订串人。
- **前台试听**：预约列表与新建表单分开；同一搜索入口显示会员、青少年学员和客户线索，保留监护人信息。姓名可带入新建学员，监护人仍需主动选择并确认授权。常规预约备注选填，取消重复预约确认；固定提交栏展示学员、上课时间和教练。选人写入资源所属组件，刷新时按 ID 保持同一对象，消除向只读计算属性写值的问题。
- **管理员课程**：课程编码由服务端生成并支持幂等重放；成人、青少年、不限直接点选。课程改为可搜索的纵向列表，区分在售与停用；编辑进入独立页面并固定保存栏。备注选填，保留课程价格、课次、有效期的一次核对。
- **主理人与赛事**：普通草稿不再重复确认；赛事隐藏自动编码，提供“开赛前一天 20:00”截止规则与自定义选项。修改开赛日只在预设模式下同步截止时间。发布、取消等操作继续保留实际核对。
- **商户与其他常规操作**：操作成功默认轻提示，消除仅用于关闭结果的点击；显式要求结果对话框的操作仍可保留。实际成交金额需填写，无成交应明确填 0。
- **库存**：可从具体库存批次发起调拨／报损，带入商品、库位和批次；只输入本次数量并选择或填写原因。提交仍校验当前库存与权限。
- **财务**：日结异常增加相关业务入口；退款／订单带入截至该营业日的范围，使用日期与下单日期区分处理。营业日统一按北京时间转换。现金差异可跳到复核区，培训可跳到对应待办组；无操作权限不展示不可访问的业务入口。

老板数据入口本来已是一次点击，本轮没有为它虚报点击数收益。财务“相关订单”是带日期范围的订单查询，不等于后台异常统计的逐笔完全匹配清单。

## 点击与输入核对

统计从已打开的业务页面开始，不包含登录、查找课次、键盘操作和异常处理。以下是本地 H5 模拟环境执行结果，不是真机耗时或认知负担百分比。

| 10 人正常课次 | 已验证操作 |
| --- | --- |
| 登记到场 | 逐人选择 10 次 + 保存 1 次，共 11 次 |
| 教练提交建议 | 打开名单 + 主动全选 + 确认，共 3 次；不扣课、不入账 |
| 管理员确认消课 | 打开名单 + 主动全选 + 确认，共 3 次 |

正常已存在会员的试听预约无需填写“预约事实与原因”。课程创建减少编码输入，适用人群不用打开和确认滚轮。退款、金额核对、真实出勤和监护人授权不以默认接受来减少点击。

## 复跑

先启动本机 mock H5：

```sh
VITE_DATA_MODE=mock pnpm --dir apps/miniapp dev:h5 --host 127.0.0.1 --port 5198
```

本机安装 Playwright/Chrome 后，从仓库根目录执行：

```sh
node scripts/h5-role-ux-acceptance.cjs
node scripts/h5-role-ux-coach-acceptance.cjs
node scripts/h5-role-ux-frontdesk-acceptance.cjs
```

脚本仅允许 localhost／127.0.0.1，检查 mock 模式并阻断外部网络请求；截图输出到 `/tmp/role-ux-smoke`。数据库测试仅接受本机且名称以 `_test` 结尾的隔离数据库。

上线时需要同时更新后端批量接口和小程序包；本轮没有新增数据库迁移。
