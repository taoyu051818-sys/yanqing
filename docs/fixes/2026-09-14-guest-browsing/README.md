# 全页面游客浏览

2026-09-14。本轮按“所有页面支持游客进入，浏览时不主动弹登录”的要求修改。此记录描述本地代码与验收，尚未重新部署 API 或上传微信开发版本。

## 行为

- 会员页面导航不再按登录状态拦截；直接链接、菜单、页面加载和筛选都可留在原页。
- 401 只清除失效会话并返回错误，网络层不再跳转登录。只有用户主动登录、报名、下单、充值、领券或保存资料等操作可进入登录流程。
- 订单、钱包、卡券、设置和邀请页提供与原系统风格一致的游客说明及可选登录按钮；不把未登录显示成账户余额为零或不存在订单。
- 课程页面先加载公开课程。我的课程/试听页可以直接打开，个人档案、报名及试听记录仅在登录后请求。可选身份同步失败不清空公开课程。
- 双打报名页也先展示公开赛事内容；个人报名、参赛资料和邀请码中的本人视图在退出登录时清理。
- 取消登录回到原页面，保留订单筛选、课程浏览和手动券码，不重新触发登录。
- 经营页面可打开介绍和访问范围说明，经营数据仍按岗位权限加载。演示工具在正式环境显示未开放说明，不自动弹提示或跳首页。

## 公开数据接口

| GET 接口 | 返回范围 |
| --- | --- |
| `/training/products/public`（新增） | 上架课程、有效班级、公开费用和容量；不含教练/助教账号、成本或学员资料 |
| `/memberships/products` | 已上架且在有效期内的会员方案和权益 |
| `/memberships/recharge-plans` | 当前生效的充值方案 |
| `/goods` | 在售商品、售价和库存；不含进价或供应商信息 |

原培训经营查询、会员配置管理、购买/充值/报名接口保留认证及岗位检查。数据库结构及依赖未变化。

## 验证与边界

- 小程序完整测试：439 项通过；最后补充双打报名游客用例并进行针对性回归，51 项通过（当前合计 440 项，未将针对性回归重复累加）。
- API 单元测试：892 项通过。327 项数据库专项用例因未提供测试库而跳过，不记为通过。
- HTTP 集成测试：37 项通过，真实控制器、查询服务及身份/角色守卫，替换数据库传输；验证匿名/过期凭据读取公开方案、敏感字段投影及写操作仍需认证。
- API 构建、小程序微信远端生产构建、类型检查通过。
- H5 使用本地 mock 数据对注册清单内全部 30 个页面逐页访问：无自动跳登录、无自动弹窗、无页面脚本报错。详情页缺少参数时展示无效链接说明。
- 额外操作检查：从“我的”进入订单并筛选；连续三次主动登录后取消；我的课程切换到公开目录后报名并取消；填写券码、确认领取进入登录、取消后保留输入。
- 375px 手机视图及 320px/横屏检查：游客说明沿用系统绿色与卡片样式，无横向溢出。
- 本轮没有执行微信真机授权、支付、退款或提交审核；H5 自动化不能代替微信真机验收。

## 更新时注意

必须先部署本次 API，再上传本次小程序；否则现有服务器仍可能对商品/会员方案返回 401，且尚无公开课程新接口。当前线上及已上传的 1.0.1 不自动获得本轮修改。

真机验收可从未登录状态进入首页、订场、活动、我的，再逐个打开订单、钱包、卡券、设置、邀请、课程、小店、会员方案。浏览和切换时不应跳登录；主动报名/领券时再登录，取消后应回原页。微信开发版上传后仍需重新提审，通过并发布才更新用户端。
