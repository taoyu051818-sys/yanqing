# 经营界面交互打磨 · 2026-09-22

本轮落实上一轮界面审查：减少重复提示、手工输入和寻找操作的滚动距离，沿用现有绿色经营界面。未改动支付、退款、库存过账的服务端业务规则。

## 已完成

| 场景 | 本轮行为 |
| --- | --- |
| 课程创建 | 字段错误只在对应字段显示一次，定位并聚焦；服务端错误在固定操作栏展示，保留填写内容。去掉顶部重复错误与 toast。 |
| 班级创建 | 编码自动生成；常规表单保留课程、名称、星期、时间、容量和主教练。助教、成本及备注按需展开，收起时仍显示成本摘要，提交确认也显示成本。 |
| 会员产品 / 充值计划 | 编码自动生成，备注选填；开始销售日使用日期选择器，长期销售使用开关。修改会员产品时继续继承原有结构化权益。 |
| 库存作业 | 采购、盘点、调拨、报损、领用和基础资料编辑进入独立路由状态，固定取消 / 保存栏；不再同屏堆叠统计、列表和表单。批次有效期使用日期选择器。 |
| 库存返回与异常 | 取消可选择继续填写；失败保留草稿；成功返回原列表。直接链接进入时返回对应业务列表。不存在的编辑对象不降级为新建；前台直接打开作业链接也不能创建。 |
| 代会员订场 | 今天默认显示当前与接下来的时段；“查看全天”仍包含已过时时段。选择会员后收起搜索列表，底栏可更换会员。原有过去 / 已占用时段的权限逻辑保留。 |
| 赛事录分 | 待录分对阵优先，已完成对阵可展开；纠正后的比分也归入已完成。深链接定位的已完成对阵保持可见。配对调整成为次级入口，已锁定时不展示无效输入表单。 |
| 场地价格 | 用紧凑时段列表显示普通价、新客价、适用日和状态；点击行修改，详情里查看生效区间及停用。未改变价格规则和历史订单。 |
| 经营分析 | 首屏四项关键指标及待办入口；其他指标、经营明细按需展开。更新财务页面中过时的“异人复核”和英文状态说明。 |
| 商户与小屏 | 核销 / 优惠券页不再混入商户档案管理；小屏排课日期独占一行，场地选项改为两列，事件表单及库存标签保持可读字号。 |

## 工程处理

- 库存表单复用原有领域 actions；新增 `use-task-page.ts` 只负责路由、草稿和返回生命周期，避免复制采购 / 过账逻辑。
- 路由参数统一校验；保留具体商品、库存批次和编辑对象上下文。
- 自动编号从已持久化的创建幂等键派生。网络失败后重试仍使用同一编号，不会因为重新生成编号破坏幂等。
- 编号工具放在经营分包内；微信构建检查无未使用主包 JS、无 mock 模块、无超限媒体。
- 日期控件复用两个小组件，分别表达“销售时间范围”和“可选有效期”，不混淆销售截止日与实物批次有效期。

## 验证

- 小程序全量测试：96 个文件、577 项通过。
- 编号工具移动到经营分包后，相关 8 个测试文件、22 项再次通过。
- Vue / TypeScript 类型检查通过。
- 生产微信小程序构建、包依赖检查、定位编译检查通过。
- 本地 H5 mock：17 个界面状态通过。涵盖课程验证及创建、班级自动编号创建、320px 排课、库存独立表单与取消 / 保存返回、缺失资料、充值创建、商户分类、经营明细、价格、录分、代订和前台只读保护。
- 375px 竖屏、844×390 横屏另查 8 个界面；启用减少动态效果与深色系统偏好时检查溢出、固定底栏位置。应用继续沿用现有浅色经营主题。
- H5 测试阻止外部请求，只操作本地 mock 数据。测试不替代微信真机键盘、原生日期选择器、系统字号和读屏验收；未宣称完成完整无障碍认证。

复现：先以 `VITE_DATA_MODE=mock` 在本机 5198 端口启动 H5，再运行 `scripts/h5-interface-polish-acceptance.cjs` 和 `scripts/h5-interface-polish-responsive.cjs`（需要 Playwright 和本机 Chrome）。

## 设计依据与交付状态

本轮应用本机 `ui-ux-pro-max` skill 的移动交互、错误定位、触控尺寸、固定操作栏与渐进披露检查；具体设计沿用此前核对的 Apple HIG、NN/g 渐进披露、WCAG 错误识别 / 避免重复输入、WeUI 原生控件习惯。它们用于制定和检查方案，不表示系统获得这些标准的认证。

本轮完成代码与本地验证，未部署服务器、未上传微信体验版。此次主要为小程序端更新，需要上传新的小程序包后才能在微信体验版验收。
