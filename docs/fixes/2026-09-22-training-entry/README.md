# 培训填写与适用人群修复（2026-09-22）

## 用户问题与处理

- 试听的“青少年学员”原为已有档案下拉框，没有录入入口。现在支持姓名搜索、新增学员、选择监护人、确认授权后保存并自动选中。不会默认选中目录首位学员，刷新目录时保留已选学员身份。没有匹配课次时明确提示先排课；可排课人员可直接进入排课。
- 课程创建的“创建原因”原先强制要求 2–300 字，截图中的空白原因会阻断保存。现在改为选填备注，未填写时以“创建课程产品”记审计；姓名、编码、课次、有效期和价格仍校验，错误就近显示并提示，失败保留草稿。重复产品编码返回明确提示。
- 通用操作弹窗原本由子组件直接修改传入的表单对象，并将 v-model 与 input 事件组合。改为单一输入事件回传表单所有者；textarea 设置固定容器属性、明确高度和占位提示。停用/启用支持常见原因快捷选择，“其他原因”自动聚焦并滚动到输入框。
- 课程适用人群增加 `ALL / 不限`。数据库、共享契约、后台、模拟接口、会员课程列表和报名一起更新。成人/青少年筛选都包含不限课程；不限课程报名时明确选择“本人”或“青少年学员”。试听按学员类型筛选匹配课次。
- 青少年规则和监护人校验继续生效；不限课程包含青少年，因此创建/启用时也按现有青少年课程规则校验。未配置已生效规则时会显示具体原因，不会绕过规则。
- 不限课包的青少年成长积分按实际学员身份处理，成人本人报名不获得青少年成长积分；冲正按原记录实际发出的积分回退。

## 真机复核步骤

1. 培训 → 试听 → 主体选择青少年学员 → 点击姓名栏 → 输入姓名搜索，或新增学员并选择监护人 → 保存后应自动回填；同名档案核对监护人。
2. 培训 → 新增课程：填写唯一编码、名称、课次、有效期、价格，适用人群选择“不限”，备注留空并保存。若青少年规则未配置，按明确提示先配置规则。重复编码应显示更换编码提示且保留输入。
3. 课程 → 停止销售 → 选择常用原因，或“其他原因”输入文字；确认后状态应更新。iPhone 打开/收起键盘后输入框和底部按钮应可用。
4. 会员课程列表：成人、青少年筛选均能找到“不限”课程；详情报名可分别选择本人和已授权学员，订单报名人应对应所选身份。
