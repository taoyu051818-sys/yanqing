# 微信开发者工具与测试 AppID 验收

本文是当前仓库的微信小程序导入、联调和实机验收手册。它针对 `apps/miniapp` 的 uni-app + Vue 3 工程；微信开发者工具导入的必须是 uni-app 编译产物，不是仓库根目录、`apps/miniapp` 或 `apps/miniapp/src`。

## 当前构建基线

- 小程序测试 AppID：`wxa457599ec4c27ad1`。
- 配置位置：`apps/miniapp/src/manifest.json` 的 `mp-weixin.appid`。
- 文件开头的顶层 `appid` 是 uni-app 的 5+ AppID，当前留空不影响微信小程序；不要把微信 AppID 填到那个字段。
- 构建后配置：`dist/*/mp-weixin/project.config.json` 的 `compileType` 为 `miniprogram`，因此项目按“微信小程序”打开，不是“小游戏”。
- 默认数据模式：`VITE_DATA_MODE=mock`。模拟模式不会访问 API，订单、身份和演示操作保存在当前微信开发者工具的本地缓存。

本机构建核验（2026-08-30）：已生成并检查 `dist/build/mp-weixin/project.config.json`，其中 `compileType=miniprogram` 且使用测试 AppID；已在微信开发者工具 Stable 2.01.2510290 导入、重新编译并渲染首页，问题面板为 0，最终预览包约 606 KB 且已成功生成二维码。点击“上传”时工具明确提示“测试号不支持上传”，因此该 AppID 只能用于预览/开发版实机检查；要上传开发版本或设置体验版，必须换成管理员授权且支持上传的正式小程序 AppID 后重新构建。mock 构建仍只能计作开发演示。

测试 AppID 只用于本地开发和预览验收，不支持上传体验版。若开发者工具提示“无权限”“AppID 不存在”或账号未加入项目，请让小程序管理员把当前微信号加入开发成员，或在 `manifest.json` 换成你有权限的 AppID 后重新构建；不要把别人的 AppID 用于正式发布。后端 `WECHAT_APP_ID` 必须与前端构建使用的 AppID 一致，`WECHAT_APP_SECRET` 只能放在 API 服务端。

## 一次性准备

1. 安装微信开发者工具稳定版，并用已加入该 AppID 项目的微信扫码登录。
2. 在仓库根目录安装依赖：

   ```bash
   pnpm install --frozen-lockfile
   ```

3. 初始化小程序环境文件（文件不要提交）：

   ```bash
   cp apps/miniapp/.env.example apps/miniapp/.env
   ```

   默认保持：

   ```dotenv
   VITE_DATA_MODE=mock
   VITE_API_BASE_URL=http://127.0.0.1:3200/api/v1
   ```

4. 启动开发构建：

   ```bash
   pnpm dev:miniapp
   ```

   命令保持运行，首次编译完成后会生成 `apps/miniapp/dist/dev/mp-weixin`。需要可上传的压缩构建时，另开终端执行：

   ```bash
   pnpm build:miniapp
   ```

   产物为 `apps/miniapp/dist/build/mp-weixin`。每次修改 `manifest.json`、环境变量或页面代码后，都要重新编译并在开发者工具点击“编译”或重新导入产物。

   上传或体验版构建前，必须把 `.env` 切到真实 HTTPS API 和远端模式；环境变量会在编译时写入包内，不能编译后再靠开发者工具切换：

   ```dotenv
   VITE_DATA_MODE=remote
   VITE_API_BASE_URL=https://api.example.com/api/v1
   ```

   确认后再执行 `pnpm build:miniapp`。如果保留 `VITE_DATA_MODE=mock`，即使目录名是 `build` 也只是本地演示包，不得上传为正式体验版。

   可在导入前用一条命令确认产物类型和 AppID：

   ```bash
   node -e "const p=require('./apps/miniapp/dist/build/mp-weixin/project.config.json'); if(p.compileType!=='miniprogram') throw Error('不是小程序模式'); console.log(p.compileType, p.appid)"
   ```

在开发者工具首页选择“**小程序**”→“+”→“导入项目”，填写：

| 字段 | 开发联调 | 上传/体验版 |
| --- | --- | --- |
| 项目目录 | `apps/miniapp/dist/dev/mp-weixin` | `apps/miniapp/dist/build/mp-weixin` |
| AppID | `wxa457599ec4c27ad1`（或管理员分配的测试 AppID） | 与发布环境一致的正式 AppID |
| 项目名称 | 延庆金羽羽毛球 | 延庆金羽羽毛球 |
| 项目类型 | 小程序（Mini Program） | 小程序（Mini Program） |

导入后可在“详情 → 基本信息/本地设置”核对：

```json
{
  "compileType": "miniprogram",
  "appid": "wxa457599ec4c27ad1"
}
```

如果界面显示“小游戏”，不要继续编译：关闭项目，确认导入的是上面的 `mp-weixin` 目录，并检查其中的 `project.config.json`。`compileType` 必须是 `miniprogram`；它是构建产物的判定依据。不要手工把小程序改成 `game`，也不要导入 `dist` 上一级目录。`project.config.json` 是构建生成文件，重新执行 uni-app 构建后会按 `manifest.json` 恢复。

开发者工具可能同时生成 `project.private.config.json`，它只保存本机设置，不要提交到仓库。

## 模拟数据验收（推荐先走这一遍）

模拟模式适合页面、路由、权限可见性和正常/异常提示验收，不代表真实微信登录、支付或跨设备数据。按以下顺序操作：

1. 点击“编译”，首次进入登录页。
2. 点击“开发联调入口”中的角色快捷按钮（会员、前台、教练、主理人、商户、管理员）。
3. 登录后进入“我的 → 管理员演示通道”，可在九种体验端之间切换：会员、前台、教练、主理人、联盟商户、财务、赛事管理员、管理员、超级管理员。
4. 切换后检查“今日营业”工作台：模块只显示当前角色有权处理的对象和待办；会员看不到员工工作台。
5. 需要从干净状态重跑时，在“管理员演示通道”点击“重置本机演示数据”，或在开发者工具“清缓存 → 清除缓存/本地存储”后重新编译。

角色验收重点：

| 角色 | 旅程和应见结果 |
| --- | --- |
| 会员 | 查看场地→创建订单→模拟支付→查看订单/五账户；浏览球局、赛事、培训、联盟券和商品。 |
| 前台 | 今日营业、场地占用、现场签到、会员查询、履约/库存待办；不能进入财务调账。 |
| 教练 | 查看自己的培训课表和学员签到，提交消课建议；不能直接确认收入。 |
| 主理人 | 查看自己发起的球局、报名和签到，结束球局后等待奖励观察期；满员球局按候补顺序递补。 |
| 赛事管理员 | 创建赛事草稿、发布后报名、签到、推进轮次、录入/纠正比分；固定双打和五轮规则不可绕过。 |
| 联盟商户 | 仅查看/核销本商户券码，提交归因或结算异议；不能使用会员场馆余额付款。 |
| 财务 | 退款审批、培训/联盟结算、日常对账和导出；制单人不能审批自己的退款。 |
| 管理员/超级管理员 | 查看全局工作台、审批和审计；超级管理员用于系统级操作。 |

模拟模式下，支付、退款、扫码和结算是本地演示动作；不要把模拟成功截图当作微信支付回调或真实资金入账凭证。

## API 联调验收

要验证持久化、角色守卫、并发和账本规则，必须切换到远端模式。先准备 PostgreSQL 和 API：

```bash
docker compose up -d postgres
pnpm --dir apps/api db:deploy
pnpm --dir apps/api db:seed
pnpm dev:api
```

另开终端，把 `apps/miniapp/.env` 改为：

```dotenv
VITE_DATA_MODE=remote
VITE_API_BASE_URL=http://127.0.0.1:3200/api/v1
```

重新执行 `pnpm dev:miniapp`，并导入/刷新 `dist/dev/mp-weixin`。本机模拟器通常可以访问 `127.0.0.1`；真机不能把手机自己的 `127.0.0.1` 当作电脑 API。真机联调应使用同一局域网可达的开发机地址（仅开发者工具并关闭域名校验时使用），或使用带有效 TLS 证书的 HTTPS 测试域名。

API 联调前确认：

- `apps/api/.env` 的 `NODE_ENV` 不是 `production`，开发登录才会开放；生产环境必须禁用 `/auth/dev-login`。
- `WECHAT_APP_ID` 与小程序构建 AppID 一致；微信登录还需要真实 `WECHAT_APP_SECRET`。
- `PAYMENT_PROVIDER=mock` 只用于接口联调；真实支付/退款需要商户号、证书、回调地址和签名验签配置。
- 请求域名、上传下载域名和 socket 域名在微信公众平台配置为 HTTPS 合法域名；不要把 `urlCheck=false` 带入正式发布。
- 开发者工具“详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”只用于本地调试，不能作为生产验收结论。

执行 `db:seed` 后，开发登录按角色选择以下种子账号（开发登录接口按角色查找，不需要输入密码）：

| 角色 | 手机号/种子账号 | 主要用途 |
| --- | --- | --- |
| 管理员 | `13800000001` | 全局工作台、审批、导出、审计 |
| 前台 | `13800000002` | 场地、签到、现场履约 |
| 教练 | `13800000003` | 培训课表和消课提案 |
| 主理人 | `13800000004` | 球局报名、签到和结束 |
| 会员 | `13800000005` | 订场、账户、培训、商品和联盟权益 |
| 联盟商户 | `13800000006` | 本商户券码和结算 |
| 财务复核 | `13800000007` | 退款、账户调整、结算与日结复核 |
| 超级管理员 | `13800000008` | 全局参数、高风险审批与应急审计 |

财务和赛事管理员可使用管理员的对应角色权限，或在 mock 管理员通道直接切换；生产环境不得依赖这些开发账号。

注意：种子手机号只是 `/auth/dev-login` 的非生产测试选择条件，不能在微信真机里当作密码登录。体验版/真机应使用已绑定到这些用户角色的微信 OpenID；若在非生产环境临时用开发登录联调，必须在 Swagger 或受控测试 API 中完成，验收记录要注明“开发登录”，并在发布前确认接口返回 401。

## 微信开发者工具常用操作

- **编译**：重新编译当前产物；改了环境变量后必须停止旧进程、重新构建再编译。
- **预览**：生成二维码，在已加入体验成员的真机微信中打开；预览二维码不等于上传审核。
- **真机调试**：连接 USB 或同一网络设备，观察真机网络、控制台和存储；逐项验证拒绝权限、弱网、前后台切换和安全区。
- **清缓存**：遇到旧路由、旧身份或 mock 订单残留时，清除编译缓存和本地存储后重新编译。
- **调试器**：Console 看异常和请求 ID，Network 看请求 URL/状态码/响应，Storage 检查 `yanqing_access_token` 与 mock 订单；不要截图或提交 token。
- **上传**：只从 `dist/build/mp-weixin` 上传，填写版本号和备注，并确认当前 AppID 是支持上传、且当前微信号有开发者权限的正式小程序 AppID；仓库内测试号 `wxa457599ec4c27ad1` 会被开发者工具提示“测试号不支持上传”。上传前先跑 `pnpm verify`。

### 上传体验版（需要管理员权限）

1. 先确认 `.env` 为 `VITE_DATA_MODE=remote`、HTTPS API，并完成 `pnpm verify` 和 `pnpm build:miniapp`。
2. 在开发者工具打开 `dist/build/mp-weixin`，点击右上角“上传”，填写版本号（例如 `1.0.0-test.1`）和本次验收说明。
3. 上传完成后，在微信公众平台“管理 → 版本管理”把开发版本设为体验版，并把验收微信号加入体验成员。
4. 用真机扫描体验版二维码，按 14 条旅程逐项执行；发现问题记录请求 ID/单据 ID，不要只记录页面截图。
5. 修复后递增版本号、重新构建和上传；不要在开发者工具直接修改生成文件来“修复”代码。

常见问题快速定位：

| 现象 | 优先检查 |
| --- | --- |
| 被识别为小游戏/页面空白 | 是否导入 `mp-weixin` 目录；检查 `project.config.json.compileType`，重新执行 uni-app 构建。 |
| AppID 无权限或不存在 | 开发者工具登录微信号是否被加入项目；构建产物 AppID 是否和管理员分配的一致。 |
| `request:fail`/合法域名错误 | mock 模式无需 API；remote 模式检查 URL、HTTPS 证书和公众平台合法域名，开发者工具本地调试才可暂时关闭校验。 |
| 开发登录返回 401 | API 的 `NODE_ENV` 是否为 `production`；生产环境按微信登录，不使用 `/auth/dev-login`。 |
| 修改代码后仍显示旧页面 | 停止旧的 `dev:miniapp`，重新编译，开发者工具清编译缓存和本地存储。 |
| 真机访问不了本地 API | 手机不能访问电脑 `127.0.0.1`；改用 HTTPS 测试域名或受控局域网代理，并确认手机与电脑可达。 |

| 13 | 权限与身份 | 各角色只能看/做授权范围内动作；测试身份切换仅开发/mock 使用，生产关闭开发登录并保留审计。 |
